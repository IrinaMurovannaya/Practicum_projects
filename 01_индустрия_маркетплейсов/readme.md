## Аналитический дашборд для маркетплейса «МаркетПро»

### Описание проекта

Заказчик — отдел маркетплейса. Нужно создать дашборд для мониторинга ключевых показателей продаж, лояльности пользователей и эффективности монетизации. Цель — повысить эффективность продаж, оптимизировать ассортимент и удержать пользователей.

**Ссылка на дашборд:** [Открыть в Apache Superset](https://superset.bi-analysts.education-services.ru/superset/dashboard/2316/)

### Структура дашборда

**Вкладка «Анализ продаж»:** GMV, средний чек, динамика заказов, топ-10 категорий, отзывы и рейтинг.

**Вкладка «Анализ пользователей»:** динамика продавцов/покупателей, конверсия, Retention, LTV, ARPU, ARPPU, DAU.

**Фильтры:** дата, категория, статус заказа, рейтинг.

### Вывод

Дашборд позволяет отслеживать финансовые показатели, баланс экосистемы, удержание пользователей и ежедневную активность. 

Ключевые сигналы: скачок/падение GMV, падение конверсии, снижение Retention.
